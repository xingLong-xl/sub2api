# 隐私政策

本隐私政策说明 **TokenPilot**（以下称“本平台”或“我们”）如何收集、使用、存储和保护你的信息。

本平台由 **Skyora International Co., Limited** 运营。使用本平台即表示你已阅读并理解本政策。

## 一、我们收集的信息

为了提供账号、API 接入、计费和安全保障服务，我们可能收集以下信息：

### 1. 账号信息

- 邮箱地址
- 用户名或昵称
- 登录凭证及账号状态
- 你主动填写的其他资料

### 2. 使用信息

- API 调用记录、请求时间、模型名称与用量
- 余额、充值、消费和账单记录
- 设备、浏览器、IP 地址及必要的访问日志
- 错误日志与安全审计信息

### 3. 支付信息

当你充值时，我们可能记录订单号、支付渠道、金额和支付状态。我们不直接存储完整的银行卡号或支付密码，相关支付信息由支付服务商处理。

### 4. Cookie 与本地存储

我们可能使用 Cookie 或浏览器本地存储维持登录状态、保存界面偏好并保障服务安全。你可以在浏览器中管理或清除这些数据，但部分功能可能因此无法正常使用。

## 二、我们如何使用信息

我们仅在以下目的范围内使用信息：

- 创建、维护和保护你的账号
- 提供 API 接入、模型转发和用量统计
- 完成充值、扣费、对账和退款处理
- 识别、预防和处理欺诈、滥用及安全风险
- 排查故障、优化服务质量和用户体验
- 遵守法律法规、响应监管或司法机关的合法要求
- 经你同意的其他用途

## 三、信息共享

我们不会出售你的个人信息。

在以下情况下，我们可能向第三方提供必要信息：

- **服务提供商**：为提供支付、邮件、云存储、日志和安全服务，向受托服务商提供必要信息
- **上游模型服务**：为完成你的请求，将请求内容转发至相应的模型服务商
- **法律要求**：根据法律法规、法院命令或政府机关的合法要求
- **保护权利**：为保护本平台、用户或公众的合法权益所必需

我们会要求相关第三方在合理范围内保护信息安全。

## 四、信息存储与保留

我们会在实现本政策所述目的所需的期限内保留信息。

- 账号信息通常在账号存续期间保留
- 账单、订单和依法需要留存的记录，按适用法律要求的期限保留
- 安全日志和访问日志按实际安全需要保留
- 超出必要期限的信息将被删除或匿名化处理

## 五、信息安全

我们采取合理的技术和管理措施保护信息安全，包括访问控制、传输加密、日志审计和权限隔离。

但互联网环境不存在绝对安全。请妥善保管账号、密码和 API Key，不要向他人泄露。如发现账号或密钥异常，请立即联系我们。

## 六、你的权利

在适用法律允许的范围内，你可以：

- 查询、更正或补充账号信息
- 删除不再需要的信息
- 撤回同意或注销账号
- 获取与账号相关的必要信息副本

部分信息因法律、财务或安全要求可能无法立即删除。你可以通过本政策末尾的邮箱提出请求。

## 七、第三方链接与模型服务

本平台可能包含第三方网站或模型服务的链接。第三方服务有自己的隐私政策，我们不控制其信息处理行为。你使用第三方服务前，应自行阅读并同意其条款。

## 八、未成年人

本平台主要面向开发者和企业用户，不面向未成年人单独提供服务。未成年人应在监护人同意和指导下使用本平台。

## 九、政策更新

我们可能根据业务、法律或技术变化更新本政策。更新后的版本会在本页面发布，并标注更新时间。重大变化时，我们会通过站内公告或其他合理方式提示。
