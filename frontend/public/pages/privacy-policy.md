请您在使用 TokenPilot 前仔细阅读本政策。您访问、注册、登录、充值、创建 API Key、调用 API、使用快速开始对话工作台或以其他方式使用 TokenPilot，即表示您理解并同意本政策。

请您注意做好个人隐私保护和安全防护。

> **数据承诺**：我们不会出售您的个人信息或用户对话数据。除您在工具页、快速开始对话工作台等产品中主动创建和保存的会话历史外，TokenPilot 不会将 API 中转调用中的用户对话正文作为平台会话历史保存。为完成模型调用，请求内容仍会在必要范围内转发给对应的上游 AI 模型服务商。

## 一、适用范围

本政策适用于 TokenPilot 提供的网站、控制台、API 接入、API Key 管理、余额和充值、用量日志、快速开始对话工作台、模型转发、技术支持和相关服务。

本政策不适用于第三方网站、第三方 AI 模型服务商、支付服务商、邮件服务商、云服务商或其他第三方独立提供的服务。您使用第三方服务时，还应阅读并遵守其隐私政策、服务条款和安全规则。

## 二、我们收集的信息

### 2.1 账户信息

为创建、验证、保护和管理您的账户，我们可能收集和处理：

- 邮箱地址；
- 用户名、昵称或账户标识；
- 密码哈希、登录状态、会话信息和安全验证记录；
- 邮箱验证码、人机校验结果、登录时间、注册时间和账户状态；
- 邀请码、邀请关系、代理/推荐计划相关信息；
- 您主动提交的客服沟通、问题反馈、发票申请或退款申请信息。

### 2.2 API Key 和访问凭证信息

为提供 API 接入和安全管理能力，我们可能处理：

- API Key 的标识、名称、创建时间、状态、权限、分组和使用记录；
- API Key 的部分脱敏信息，用于识别、展示、排障和安全审计；
- 账户和 API Key 的启用、禁用、删除、复制配置等操作记录。

我们不会在普通日志、公开页面或对外文档中主动展示完整 API Key。您也应妥善保管 API Key，避免泄露。

### 2.3 API 使用数据

当您通过 TokenPilot 调用模型 API 时，我们可能收集和处理与请求相关的必要数据，包括：

- 请求时间、请求路径、接口类型、模型、分组、渠道和状态；
- Token 消耗、缓存用量、推理用量、计费金额、余额变化和用量统计；
- 响应耗时、错误码、错误信息、重试、超时、上游返回状态和排障信息；
- API Key 标识、用户 ID、账户状态、余额状态和权限校验结果；
- 为安全、风控、计费、排障和合规所需的必要技术信息。

API 中转调用的请求内容可能会被发送至对应的第三方 AI 模型服务商，以完成模型生成、推理或响应。我们会围绕服务提供、计费、排障和安全合规进行必要处理。

除您主动创建和保存的会话历史外，TokenPilot 不会将 API 中转调用中的用户对话正文作为平台会话历史保存。

### 2.4 快速开始对话数据

当您使用控制台内置的快速开始对话工作台或工具页对话功能时，TokenPilot 会为您保存会话历史，以便您刷新页面、切换浏览器或后续继续查看和使用。

相关数据可能包括：

- 会话标题、会话 ID、创建时间、更新时间；
- 用户消息、助手回复、推理内容、错误状态和错误码；
- 使用的模型、分组、请求状态和上下文信息；
- 您对会话或消息进行的新建、重命名、编辑、删除、重新生成等操作记录。

您可以在控制台中删除会话或消息。删除后，相关内容会按系统机制删除或不可见；因备份、审计、争议处理、安全排查或法律法规要求，部分记录可能在必要期限内继续保存。

### 2.5 计费、充值和发票信息

为完成充值、扣费、账单、退款、返佣、发票和财务管理，我们可能收集和处理：

- 充值订单号、金额、支付方式、支付状态、支付时间和回调结果；
- 消费记录、余额变化、用量金额、退款申请和处理状态；
- 推荐计划、邀请关系、返佣配置、待确认金额和相关结算记录；
- 如您申请发票，您提交的开票主体、税号、联系信息、订单信息、收件信息和其他开票所需资料；
- 支付服务商返回的必要交易状态和订单信息。

### 2.6 技术日志和设备信息

为保障服务运行、安全防护、故障排查和反滥用，我们可能收集和处理：

- IP 地址、请求时间、请求路径、HTTP 状态、网络状态和访问日志；
- 浏览器类型、设备类型、操作系统、语言、User-Agent 和基础环境信息；
- 登录失败、异常访问、频率异常、并发异常、攻击探测、接口错误和系统异常记录；
- Cookie、本地存储或类似技术产生的必要信息，用于登录状态、偏好设置和安全校验。

- 保护 TokenPilot、用户、第三方和公共利益的合法权益。

我们不会出售您的个人信息或用户对话数据。

## 四、Cookie 和类似技术

TokenPilot 可能使用 Cookie、本地存储、会话存储或类似技术，用于：

- 保持登录状态和会话安全；

您可以通过浏览器设置管理或拒绝 Cookie，但这可能导致登录、控制台、支付回跳、偏好保存或安全校验等功能无法正常使用。

## 六、数据存储和保留

### 6.1 存储位置

TokenPilot 会根据服务部署、云服务、上游模型服务、支付服务和运营需要存储或处理数据。部分 AI 模型请求内容可能因调用境内外第三方模型服务商而被传输至对应服务商进行处理。

我们会采取合理措施保护传输和存储过程中的数据安全，并在必要范围内进行跨服务、跨区域或跨境处理。您使用服务即表示理解此类处理可能是完成模型调用和服务交付所必需的。

### 6.2 保留期限

我们会在实现本政策所述目的所需的最短合理期限内保存您的信息，除非法律法规、监管要求、争议处理、财税合规、安全审计或业务风控要求更长保存期限。

| 数据类型 | 保留口径 | 主要原因 |
| --- | --- | --- |
| 账户信息 | 账户存续期间及法定或合理业务保留期限 | 提供服务、账户安全和法律合规 |
| API Key 和使用日志 | 计费、排障、安全、审计和合规所需期间 | 用量核对、风控、故障排查和争议处理 |
| 充值、消费、退款、返佣和发票记录 | 按财务、税务、支付和合规要求保存 | 财务结算、税务合规和支付争议处理 |
| 快速开始会话数据 | 用户保留期间保存；用户删除后按系统机制删除、不可见或在备份/审计周期后清理 | 继续查看会话、恢复上下文和用户主动保存记录 |
| 技术日志和安全日志 | 按故障排查、安全防护、风控和合规需要保存 | 服务稳定性、安全审计和反滥用 |
| 客服、投诉和争议资料 | 处理期间及争议解决后的必要期限 | 响应请求、解决争议和维护合法权益 |

### 6.3 删除和注销

您可以联系客服申请删除个人信息、注销账户或处理快速开始会话数据。我们会在核验身份、确认请求范围和评估法律、财务、安全、争议保留要求后处理。

以下信息可能无法立即删除或需要继续保存：

- 法律法规、监管、财税、审计要求必须保留的信息；
- 支付、订单、发票、退款、账务和争议处理所需记录；
- 安全事件、违规、欺诈、攻击、滥用调查所需记录；
- 已匿名化、去标识化或无法识别特定个人的信息；
- 备份系统中尚未到达清理周期的数据。

## 七、数据安全措施

我们采取合理的技术和管理措施保护您的信息，包括：

- 使用 HTTPS/TLS 加密传输；
- 对密码等敏感凭证进行哈希或加密处理；
- 对 API Key、支付密钥、SMTP token、数据库密码等敏感配置进行权限隔离和脱敏管理；
- 通过访问控制、权限分级、日志审计和安全监控限制数据访问；
- 对异常访问、攻击、滥用、暴力破解、批量注册等行为进行检测和处置；
- 定期进行备份、监控、升级和安全加固；
- 要求有权限的人员按最小必要原则访问数据。

尽管我们会尽合理努力保护数据安全，但互联网环境不存在绝对安全。因不可抗力、第三方原因、用户自身泄露、攻击行为或非 TokenPilot 过错导致的信息风险，TokenPilot 将依法处理并尽合理努力降低影响。
