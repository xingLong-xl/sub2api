# 关于我们

TokenPilot 是一个面向开发者、团队与企业的 AI 模型统一接入平台，由 **Skyora International Co., Limited** 运营。

我们希望通过统一、稳定、透明的 API 入口，让用户不必分别对接不同厂商的模型服务，即可在自己的产品、工具和工作流中使用多种主流 AI 能力。

## 我们提供什么

- **统一入口**：通过兼容 OpenAI 的接口访问多种模型与能力。
- **稳定转发**：多线路与多上游调度，尽量降低单一渠道波动带来的影响。
- **用量可观测**：提供调用记录、用量统计与费用明细，便于团队管理成本。
- **灵活接入**：支持 API Key、Claude Code、Codex 等常见开发方式。
- **透明计费**：按实际使用量计费，价格与扣费记录清晰可查。

## 我们的原则

### 稳定优先

持续监控上游服务状态，尽可能为用户提供稳定、可持续的模型访问能力。

### 信息透明

在合理范围内公开模型、价格、用量和计费信息，让用户清楚知道自己的使用情况。

### 尊重规则

我们尊重上游模型厂商的服务条款与使用政策，并要求用户在使用本平台时遵守适用的法律法规及平台规则。

### 保护隐私

我们重视用户数据与账号安全，仅在提供服务所必需的范围内处理信息，并采取合理的安全措施。
